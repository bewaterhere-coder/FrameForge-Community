# Sample Game Asset Rules

- Keep project-owned visual assets under `assets/`.
- Prefer SVG for the small sample icon and use nearest-neighbor filtering for pixel-style raster art if raster assets are added later.
- Do not add external asset packs without recording source, license and version.
- Keep generated or downloaded assets out of runtime code.
- This sample uses code-drawn shapes for the game scene and has no third-party asset dependency.
